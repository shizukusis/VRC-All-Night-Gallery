# VRC-All-Night-Gallery

VRChat ワールド「All Night」の写真立てに表示する写真置き場です。

## 使い方

- `photos/` に画像 (jpg / jpeg / png / webp / gif / bmp) を入れて push すると追加されます。
- `photos/` から消して push すると削除されます。
- GitHub Actions が 2048px 以内に縮小・EXIF 除去して GitHub Pages に公開します。
  反映まで数分、ワールドには次に作られたインスタンスから反映されます。

公開先: https://shizukusis.github.io/VRC-All-Night-Gallery/photos/index.txt
